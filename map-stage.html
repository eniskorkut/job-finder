TELEGRAM VIP BİLDİRİM BOTU
BAĞLI // AKTİF
Kurulum ve Token Alma Rehberi (Adım Adım) ~3 DK
Önkoşul: Aktif Telegram Hesabı @BotFather'ı Aç
1 @BotFather ile Yeni Bot Oluşturun

Telegram'da @BotFather ile sohbet başlatın, /newbot komutunu gönderin. Botunuza bir ad ve sonu mutlaka bot ile biten bir kullanıcı adı verin (örn: benim_is_botum).

2 Bot Token'ı Kopyalayın ve Forma Ekleyin

BotFather'ın size verdiği 123456789:ABC... biçimindeki HTTP API belirtecini kopyalayıp aşağıdaki "Telegram Bot Token" alanına yapıştırın. Bu anahtar sunucuda güvenli şekilde şifreli saklanır.

3 Botunuza /start Mesajı Gönderin

Telegram uygulamasında yeni oluşturduğunuz botu bularak sohbet açın ve /start mesajı gönderin. Bu adım, Telegram güvenlik protokolü gereği botun size mesaj iletebilmesi için zorunludur.

4 Chat ID'yi Algılayın ve Test Mesajı Gönderin

Aşağıdaki "Chat ID'yi Algıla" butonuna tıklayın. Sistem botun getUpdates kanalından gelen son mesajı okuyarak sayısal Chat ID'nizi otomatik bulur. Ardından "Test Mesajı Gönder" ile doğrulamayı tamamlayın.

Sık Karşılaşılan Sorunlar (FAQ)
? Bot token geçersiz (401 Unauthorized):

Token'ın başında veya sonunda boşluk kalmadığından emin olun. Gerekirse BotFather'dan token'ı tekrar alıp yapıştırın.

? Sohbet bulunamadı:

Botunuza henüz /start göndermediniz. Önce botunuza bir mesaj yazıp hemen ardından "Chat ID'yi Algıla"ya basın.

? Bildirimler ne zaman gelir?:

Yalnızca belirlediğiniz eşleşme eşiğini (örn. %90) aşan nitelikli ilanlar tespit edildiğinde gönderilir. Aynı ilan için mükerrer bildirim kesinlikle iletilmez.

GMAIL E-POSTA SENKRONİZASYONU
SENKRONİZE
Gmail Kurulum ve Yetkilendirme Rehberi ~5 DK
YÖNTEM 1: UYGULAMA ŞİFRESİ (EN HIZLI & ÖNERİLEN — 2 DK) Google Güvenlik ↗
  1. Google Hesabınızda Güvenlik → 2 Adımlı Doğrulama'nın açık olduğundan emin olun.
  2. Arama çubuğuna "Uygulama Şifreleri" (App Passwords) yazın veya doğrudan sayfaya gidin.
  3. Uygulama adı olarak Job Hunter yazın ve "Oluştur" butonuna basın.
  4. Google'ın ürettiği 16 haneli sarı alandaki özel şifreyi kopyalayıp aşağıdaki "Uygulama Şifresi" kutusuna yapıştırın.
YÖNTEM 2: GOOGLE CLOUD OAUTH 2.0 WEB APPLICATION Google Cloud Console ↗

1. console.cloud.google.com adresinde "Job Finder" adıyla yeni bir proje oluşturun.

2. APIs & Services > Library bölümünden Gmail API'yi aratıp etkinleştirin (Enable).

3. OAuth consent screen sekmesinde User Type olarak External seçin. Test users adımında kendi Gmail adresinizi mutlaka ekleyin.

4. Credentials > Create credentials > OAuth client ID > Web application seçin. (DİKKAT: 'API Key' değil, Web Application seçilmelidir).

5. Authorized redirect URIs alanına http://localhost:8000/api/v1/integrations/gmail/callback adresini ekleyin.

6. Oluşan Client ID ve Secret değerlerini kaydedin.

Veri Güvenliği: Yalnızca gmail.readonly izni talep edilir. Parolanız asla Job Hunter sunucularında saklanmaz. Posta silme veya gönderme yetkisi kesinlikle talep edilmez.
Sık Karşılaşılan Sorunlar
? 7 Gün Sonra Bağlantı Uyarısı (Testing Modu):

Google Cloud'da uygulama test modundayken yetki belirteçleri 7 gün geçerlidir. Süre bittiğinde tek tıkla yeniden yetkilendirebilir veya projeyi üretime (Production) alabilirsiniz.

? redirect_uri_mismatch Hatası:

Google Console'a eklenen Redirect URI ile yönlendirilen adres birebir aynı olmalıdır (port ve / işaretine dikkat edin).

HOTMAIL / OUTLOOK (MICROSOFT ENTRA)
MS GRAPH API
Microsoft Entra ID Entegrasyon Rehberi ~5 DK
Önkoşul: Aktif Microsoft / Outlook / Hotmail Hesabı Entra Portal'ı Aç
1 Microsoft Entra'da Uygulama Kaydı Başlatın

entra.microsoft.com adresine gidin. Sol menüden Applications → App registrations sayfasına geçin ve "+ New registration" butonuna basın.

2 Hesap Türünü Doğru Seçin (Kritik Adım)

Ad alanına Job Hunter yazın. Supported account types bölümünde MUTLAKA "Personal Microsoft accounts only" veya "Accounts in any organizational directory and personal Microsoft accounts" seçeneğini işaretleyin. (Kişisel hesaplar için asla Single tenant seçmeyin!).

3 Web Platformu ve Redirect URI Ekleyin

Redirect URI bölümünde platform olarak "Web" seçin ve adres olarak http://localhost:8000/api/v1/integrations/outlook/callback yapıştırıp Register'a basın.

4 Client Secret Oluşturun — VALUE KOLONU UYARISI

Sol menüden Certificates & secrets sekmesine geçin. "+ New client secret" butonuna tıklayın. Açıklama yazıp kaydedin. DİKKAT: "Secret ID" şifre değildir; oluşan tablodaki "Value" (Değer) kolonundaki metni kopyalayın! Sayfadan ayrılırsanız Value bir daha görüntülenemez.

5 API İzinleri ve Kiracı Bilgisi

API permissions sayfasında Microsoft Graph altında Mail.Read ve User.Read izinlerinin bulunduğundan emin olun. Kişisel hesaplar için Kiracı (Tenant) değeri olarak consumers kullanılır.

Sık Karşılaşılan Sorunlar
? Secret ID ile Value Farkı Nedir?:

Secret ID yalnızca anahtarın GUID kimliğidir. Value ise şifrenin kendisidir. Secret ID girilirse AADSTS7000215 (invalid_client) hatası alınır.

? Yönetici Onayı (Admin Consent) İsteniyor:

Kişisel Hotmail/Outlook hesaplarında kiracı olarak consumers tanımlandığında yönetici onayı gerekmez. Kurumsal hesaplarda şirket IT yöneticisinin onayı gerekir.
